Isi Paket

Tujuh modul, satu alur kerja gudang bahan kimia.

Struktur yang sama persis dipakai untuk mengelola stok laboratorium sungguhan — tinggal Anda ganti isinya dengan data sendiri.

MOD-01

Master Chemical

Database induk bahan kimia: kode, nama, kategori, dan atribut keselamatan.

MOD-02

Master Stock

Stok per batch dengan COA terlampir per lot, bukan per jenis bahan.

MOD-03

Transaksi

Pencatatan masuk/keluar dengan penguncian atomik agar stok tidak bentrok.

MOD-04

Stock Report

Rekap stok teragregasi per kode bahan, siap dibaca dalam sekali lihat.

MOD-05

Rekap Bulanan

Ringkasan pergerakan stok bulanan untuk laporan ke atasan atau audit.

MOD-06

Log Aktivitas

Jejak audit tiap perubahan data — siapa, kapan, dan apa yang diubah.

MOD-07

Settings

Kelola pengguna, peran akses, logo, dan kop surat untuk cetak PDF.

Detail Teknis

Dibangun untuk operasional harian, bukan sekadar demo.

Fitur-fitur ini sudah berjalan dan teruji di implementasi aslinya sebelum dijual sebagai template kosong.

SCAN

Pemindaian QR/barcode via kamera, dengan scanner terpisah agar tidak terhalang batasan iframe Apps Script.

LABEL

Label barcode Code128 dibuat otomatis dari kode + nomor batch bahan.

CETAK

Export PDF laporan lengkap dengan kop surat dan blok tiga tanda tangan.

AKSES

Hak akses per peran ditegakkan di sisi tampilan maupun di sisi server.

GRAFIK

Visualisasi tren stok dan pergerakan menggunakan Google Charts.

KUNCI

LockService mencegah dua transaksi menimpa data pada saat bersamaan.

Yang Anda Terima

Kanvas kosong, bukan data orang lain.

Ini poin yang paling sering ditanya calon pembeli — jadi kami buat jelas sejak awal.

Termasuk dalam pembelian

  • Source code lengkap — backend Apps Script & frontend HTML/CSS/JS
  • Template struktur Google Sheet siap pakai, kosong tanpa isi
  • Panduan instalasi & langkah deploy dari nol
  • Struktur peran akses (Admin/Staff/Analis) siap dikonfigurasi
  • Update perbaikan bug ringan selama masa berlaku yang disepakati

Tidak termasuk

  • Data bahan kimia, stok, atau riwayat transaksi milik implementasi lain
  • Hosting berbayar — semua berjalan gratis di akun Google pembeli
  • Support tak terbatas selamanya (lihat rincian tiap paket)
  • Hak jual ulang atau distribusi ulang source code
